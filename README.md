# DataPulse – Enterprise Analytics Platform

##  Overview

DataPulse is a full-stack data analytics platform designed to transform raw eCommerce data into actionable business insights through interactive dashboards, KPIs, and AI-powered forecasting.

This project was developed using an **iterative software engineering approach**, focusing on building a scalable data pipeline and analytics system.

---

## ⚙️ Tech Stack

* Python
* Streamlit (Frontend)
* Pandas (Data Processing)
* Plotly (Visualization)
* PostgreSQL (Database – Supabase)

---

##  Features

*  User Authentication System
*  Interactive Business Dashboard
*  KPI Metrics (Revenue, Orders, Customers, AOV)
*  Data Visualization (Area Charts, Pie Charts)
*  AI Sales Forecasting (Planned / Partial)
*  Data Pipeline Monitoring
*  Data Table Exploration

---

##  System Architecture

The system follows a structured pipeline:

1. Data Ingestion (CSV → Database)
2. Data Transformation (Cleaning & Feature Engineering)
3. Analytics Dashboard (Visualization & KPIs)
4. Forecasting Module (ML-based predictions)

---

##  Development Process

This project follows an **Iterative Development Model**:

* Iteration 1: UI/UX Design & Initial Implementation
* Iteration 2: Data Pipeline + Dashboard Integration
* Iteration 3: Forecasting & Advanced Features (In Progress)
